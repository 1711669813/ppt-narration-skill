# PPT 智能讲解视频生成器

**ppt-narration-skill**：面向 AI Agent 的 PPT 讲解视频生成 Skill，支持中文配音、同步高亮、字幕与讲稿对照表。

这个包的作用：**把一个 .pptx 变成一支"演讲人讲解 PPT"风格的 1080p 视频**——保留原页顺序/文字/图片/版式不动，逐页配上自然的中文口语讲稿（解释重点、不逐字念），用普通话人声配音，按配音实际时长自动翻页，并且在讲到某一部分时**在画面上把那一部分标出来**（高亮框 / 下划线 / 自动放大），最后同时给出"页码—讲稿—时长"对照稿和一份外挂字幕。

把整个文件夹（或 zip）拖进任意支持文件上传的大模型对话里，按下面的"最短指令"说一句需求，模型就可以照 `SKILL.md` 跑完整流程。

---

## 输出目录规则

每次调用本包，新生成的所有任务内容统一保存在**本包根目录下的 `results/`**，包括成片、字幕、讲稿与 cue、试听音频、页面图、坐标数据、时间轴、渲染帧、复核截图、报告、日志、临时文件及模型缓存。开始前创建该目录；需要区分任务时使用 `results/<任务名>/`。

脚本默认自动定位包内 `results/`。`BUILD_ROOT`、`OUT_DIR`、`--root` 和 `--out` 的相对路径均以 `results/` 为基准，绝对路径也必须在其中；指向外部的旧配置会报错。模型另外生成的文件、命令重定向和临时辅助脚本也必须遵守此规则。原始 PPT 仍从用户提供的位置读取。


## 1. 最短指令（直接复制给模型）

> 用这个包里的 SKILL.md 流程，把 `<你的 PPT 路径>` 做成讲解录屏视频：
> 0）每次生成前先展示讲解风格菜单让我选择，按我选的风格写稿、举例和安排幽默；
> 1）先告诉我有哪些中文音色并生成试听片段让我选；
> 2）问我要不要字幕；
> 3）画面标记用"高亮框 + 下划线 + 自动放大"混用，首页、末页和每页开头"这页讲什么"的句子不要标记，背景压暗轻一点；
> 4）逐页写口语讲稿，专业术语/数字/项目名必须和 PPT 一致，材料里没有的事实不要编；
> 5）总时长不超过 10 分钟，成片 1080p MP4；
> 6）最后给我一份"页码—讲稿—预计时长"对照稿。
> 所有新生成的内容放到包内 results 文件夹下。

模型会先让你选择本次讲解风格，并问清音色/字幕，再依次做：抽内容与坐标 → 导出页面图 → 按所选风格写讲稿（cue 化）→ 配音 → 渲染合成 → 生成对照稿与字幕 → 自检。本次请求已指定风格就直接采用，同一任务修稿沿用本次选择，新任务不会自动沿用上次风格。

### 可选讲解风格

| 编号 | 风格 | 特点 |
|---|---|---|
| 1 | 专业商业汇报 | 结论先行，正式克制，突出依据与行动 |
| 2 | 严谨学术汇报 | 问题、方法、结果与局限，保留专业严谨性 |
| 3 | 生动文科课堂 | 问题引入，亲切幽默，结合情境与例子讲清知识点 |
| 4 | 轻松幽默科普 | 通俗解释，生活类比，适度幽默 |
| 5 | 耐心实操培训 | 分步骤说明，练习情境与易错点 |
| 6 | 故事叙述 | 用线索与转折串起内容，增强画面感 |
| 7 | 热情演讲动员 | 有节奏、有感染力，突出意义与行动 |
| 8 | 简洁重点速览 | 抓核心结论与依据，适合快速预览和复习 |
| 9 | 自定义或组合 | 如“文科课堂＋少量幽默”“科普但不要网络梗” |

回复编号、名称或自己的描述即可。风格和音色单独选择；课堂、科普会优先给难懂概念加入简短例子，再回扣知识点。新增假设或类比会明确说明，不编造真实案例、数据、史实或引文。详细规则见 [references/narration-styles.md](references/narration-styles.md)。所选风格记录在结果目录的 `cues.py`，并显示在讲稿对照稿顶部；视频、讲稿、字幕和中间文件仍统一放在本包 `results/`。

## 2. 整个工作流（每一步在干什么、为什么）

| 步 | 脚本 | 做什么 | 关键点 |
|---|---|---|---|
| 0 | `scripts/00_check_env.py` | 环境自检 | 找到能装包的 python、确认 ffmpeg 在 PATH、Windows 上确认 PowerPoint 可用、edge-tts 能否联网 |
| 1 | `scripts/01_extract_ppt.py` | 抽每页文字 + 每个形状的归一化坐标 + 演讲者备注 | **必须解析组合(group)**，否则坐标全错；表格行坐标留给渲染脚本按行高现算 |
| 2 | `scripts/02_export_slides.py` | 把每页导出成 3840×2160 的 PNG | 用 PowerPoint COM（保真最高、不弹窗）；Linux/macOS 用 LibreOffice。**一定导 4K**，放大时才清晰 |
| 3 | 写讲稿 | 产出 `cues.py`：一句 = 一段口播 + 一个画面标记 | 见 `prompts/01_写讲稿与cue.md`；这是全流程里最需要人/模型判断的一步 |
| 4 | `scripts/03_build_video.py` | 配音（edge-tts，带**词级时间戳**）→ 句子对齐 → 逐帧渲染标记 → 合成 MP4 ＋ `.srt` | 一页一个 mp3 保证语气连贯；带 hash 缓存，改一页只重跑一页 |
| 5 | `scripts/04_make_sheet.py` | 生成对照稿（总览表 + 逐句表 + 讲稿全文），保存到 results | 用于核对"这句话在第几秒、当时画面标的是哪块" |
| 6 | `scripts/05_verify.py` | 验收 | 容器参数/时长、逐句帧比对、**放大几何**、黑边、ASR 抽查标记与台词是否一致 |
| 7 | `scripts/06_burn_subtitles.py`（可选） | 把 `.srt` 烧进画面 | 只在用户明确要"画面里带字幕"时用 |

### 画面标记的四种方式（不会每句都标）

| 标记 | 画面效果 | 什么时候用 |
|---|---|---|
| `none` | 整页原样，不压暗、不画框、不放大 | **首页、末页**；每页开头"这页讲什么"的页标题/导语；纯过渡句 |
| `line` | 轻轻压暗 + 目标下方一条下划线 | 说明行、提示行、"待确认"事项、口径文字 |
| `box` | 压暗 + 高亮框（不放大） | 较宽的卡片带、表格行、流程条、通栏 |
| `zoom` | 压暗 + 高亮框 + 自动放大（约 1.1–2.5 倍） | 较小的卡片、表格行、图、流程小块 |

压暗强度（可调）：`box/zoom` → `DIM_BOX = 72`（≈28% 黑）；`line` → `DIM_LINE = 46`（≈18% 黑）；`none` → 0。**觉得黑就调小这两个数，别把标记删掉。**

### 时长怎么控

- 预算：rate +6% ≈ 0.194 秒/字（含标点），rate +8% ≈ 0.183 秒/字；总时长 ≈ Σ口播 + 页数×1.0 秒（翻页停留）。
- 先按预算写，**用 TTS 实测再调**；接近上限时优先压缩讲稿（删重复、删能从画面看出的列举），不要漏重点，也不要靠砍翻页停留省时间。
- 正常可达规模参考：13 页、90 个讲解单元、约 3000 字 ≈ **9 分 42 秒**。

## 3. 环境要求与安装

- **Python 3.9+**，能 `pip install`（Windows 上若默认解释器没有 pip，用 `py -0` 列出的、或 anaconda 的解释器）。
- **ffmpeg / ffprobe 必须在 PATH**（合成、取音频时长、抽帧都靠它）。
- **Windows 推荐装 Microsoft Office**（用 PowerPoint COM 导页，保真最高）；没有 Office 时用 LibreOffice（`soffice`），`02_export_slides.py` 里有备选命令。
- 联网：配音走 edge-tts（微软在线语音，免费），音色是**服务端模型**，本包不需要下载。

```bash
# Windows
install.bat
# macOS / Linux
bash install.sh
# 或手动
pip install -r requirements.txt
```

依赖清单见 `requirements.txt`，逐条写了用途。可选（只在做 ASR 复核时）见 `models/README.md`。

## 5. 常见问题

- **没声音 / 配音失败**：先 `edge-tts --list-voices | head` 看能否联网；公司网络拦 websocket 时会失败，换网络或用手机热点试。
- **画面被拉扁或出现黑边**：放大窗口的宽高比算错了。归一化坐标下 16:9 页面里的 16:9 窗口＝正方形（`vw == vh`），`03_build_video.py` 里有断言；`05_verify.py` 会独立检出这个问题。
- **字幕要不要烧进画面**：默认只给 `.srt`，播放器可自己开关；烧入需要二次编码，画质略降，所以默认不做。
- **原 PPT 动画**：静态翻页视频无法逐帧还原动画，统一以"完整页面"呈现（内容一个不少）。
- **改一句话要重跑多久**：TTS 有缓存，只有被改的那一页会重新配音；整片重渲染约 8–10 分钟（视机器）。
- 更多报错与处理见 `references/troubleshooting.md`。
