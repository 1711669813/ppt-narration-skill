# 提示词 01：写讲稿并 cue 化

输出位置：所有新生成的文件（含讲稿、cue、试听、报告和中间文件）保存到本包 `results/` 或其任务子目录下。

把本文件 + `references/cue-rules.md` + `references/narration-styles.md` 中所选风格的规则 + 本次用户的风格选择 + 第 1 步产出的坐标表（`shapes_geom.json` / 打印出来的坐标表）+ 每页文字（`slides.txt`）与备注一起给模型。尚未收到本次风格选择时，先展示风格菜单并等待回答，不自动采用正式汇报。下面是可直接复制的提示词。

---

你是中文 PPT 视频讲稿作者。我会给你一个 PPT 的**逐页文字与备注**和**每个形状的归一化坐标（0–1，相对页面宽高）**。请按本次用户选定的讲解风格与受众写讲稿，并切成 cue 列表；表达规则见 `references/narration-styles.md`，不要固定套用商业或技术汇报。

本次选择：风格＝<用户选定名称>；受众＝<用户指定或由材料推断>；幽默＝<程度>；举例＝<方式>；补充要求＝<用户自定义要求>。风格尚未选定时不进入写稿步骤。

**输出格式**（Python 代码，直接可跑）

```python
NARRATION_STYLE = {"id": "<风格标识>", "name": "<所选名称>", "audience": "<受众>",
                   "humor": "<程度>", "examples": "<方式>", "requirements": "<补充要求>"}
CUES = {
 <页码>: [
   {"t": "这一句要念出来的话。", "r": [[x0, y0, x1, y1]], "lb": "这一块的中文名", "m": "标记方式"},
   {"t": "…", "tr": ["表格 11", [1]], "r": [], "lb": "…", "m": "…"},   # 表格按行高亮
 ],
}
MODES = { <页码>: ["none", "line", "box", "zoom", …] }   # 也可直接写进每个 cue 的 "m"
```

**讲稿要求**

1. **是"讲"不是"念"**：解释这段内容的意思和重点，不要逐字朗读幻灯片文字。
2. **专业术语、数字、项目名称必须与 PPT 完全一致**；PPT 里写 `CO₂` 口头说"二氧化碳"，`kWh` 说"千瓦时"，`≤50` 说"五十及以下"，`AI`、`H01`、`客户A` 之类照原样读。
3. **材料里没写的事实一律不要编**（不要补真实数据、不要替客户下结论、不要说"效果会很好"这类没有依据的话）。可以按所选风格添加简短的假设情境或类比，用“假设”“打个比方”等明确标示，仅解释现有知识点，不杜撰史实、研究、引文或真实案例。
4. PPT 或演讲者备注里标注了"虚拟数据 / 占位符 / 待确认"的，要如实带一句（例如"这一条还需要与客户确认"）。
5. **页与页之间要有过渡**（"先看…""接着看…""这一页是…""最后是…"），让整支视频连成一段话。
6. 语气、结构、幽默程度和举例按本次所选风格执行；文科课堂、科普对难懂的核心概念优先加入贴切例子并回扣知识点，不强行每页举例；每句 1–3 行，一页 5–10 句，例子也计入 cue 和时长。
7. 句末标点决定停顿：完整的句子用"。"；并列的列表项之间用"；/，"（能省下不少停顿时间，对总时长帮助很大）。
8. 专业名词第一次出现时按受众知识基础给必要的口语解释；课堂、科普可用简短类比说明，但须保留关键条件与适用范围，不引入材料外未经验证的事实。

**画面标记要求**（每个 cue 必须指定 `m`；有页面目标时指明“这句话在讲页面的哪一块”，无目标时保持整页）

- `r` 用坐标表里那个形状/块的包围盒，可以合并同属一组的多个矩形；**不要横跨整页**，否则标记失去指向性。
- 页标题、导语这种"这页讲什么"的句子 → `m="none"`；**首页、末页的所有句子 → `m="none"`**。
- 例子关联已有概念时只标记该概念；独立假设、提问、幽默和过渡无页面目标时用 `r=[]`、`m="none"`、明确的 `lb`，不编造坐标或修改 PPT。
- 较宽的卡片带 / 表格行 / 流程条 → `m="box"`；较小的卡片、图、流程小块 → `m="zoom"`；说明行、提示行、"待确认"文字 → `m="line"`。
- 别让连续 4 句以上都用同一种标记；`none` 和 `line` 穿插进来，画面才不闷。

**自检**（写完后逐条核对并在回答里给出结论）

- 每页 cue 数 5–10；每句 1–3 行口语长度；
- 首页、末页是否全部 `none`；页标题/导语是否 `none`；
- 四种标记是否混用（`none/line/box/zoom` 都有）；
- 所有 `r` 坐标是否落在 0–1 且不越出页面；`tr` 的表名与行号是否真实存在；
- 术语/数字/项目名是否与 PPT 完全一致；
- 实际讲稿是否符合本次风格与受众，而不只是修改 `NARRATION_STYLE`；举例是否明确为假设/类比，适度幽默是否帮助理解；所有新增口播是否均写入 `t`，用于配音、对照稿与字幕；
- 估算总时长 = Σ字数 ÷ 5.2 字/秒 + 页数 × 1.0 秒，是否小于我给的上限；超了就压缩讲稿（先删可从画面看出的列举与重复），**不要漏重点**。
