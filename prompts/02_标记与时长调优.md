# 提示词 02：标记方式、压暗强度与时长调优

输出位置：所有新生成的文件（含讲稿、cue、试听、报告和中间文件）保存到本包 `results/` 或其任务子目录下。

用于成片出来后做"口味调整"和"压时长"。把视频参数（`timing2.json` 里的逐页时长）和用户意见一起给模型。

---

**A. 用户说"背景太暗了"**

改 `scripts/03_build_video.py` 顶部两个常量（数值＝黑色蒙版的透明度，0–255）：

```python
DIM_BOX  = 72     # box / zoom 标记之外的区域（默认 ≈28% 黑；觉得暗就调到 56 甚至 40）
DIM_LINE = 46     # line 标记之外的区域（默认 ≈18% 黑）
```

只改数值不要动标记逻辑；改完必须重渲染（帧会全变），并重跑 `05_verify.py` 的几何检查。

**B. 用户说"不要每句都标记 / 某几句不要标记"**

在 `cues.py` 的 `MODES` 表（或每个 cue 的 `"m"`）里把对应位置改成 `"none"`。判定规则：

- 首页、末页 → 全部 `none`；
- 每页开头说明"这页讲什么"的页标题/导语 → `none`；
- 纯过渡句、总结句（"下面进入第二部分"）→ `none`；
- 说明行、提示行、待确认文字 → `line`；
- 较宽的通栏/卡片带/表格行/流程条 → `box`；
- 较小的卡片、图、流程小块 → `zoom`。

改完只重跑 03（TTS 有缓存，未改动的页不会重新配音）。

**C. 用户说"太长/太短"**

- 压缩（不删重点的前提下，按收益排序）：① 把列表项之间的"。"改成"；"（每页能省 1–3 秒）；② 删掉重复叙述与"可以从画面看出"的列举；③ 合并过碎的 cue（两个短句并成一句）；④ 才把 `TTS_RATE` 从 `+6%` 提到 `+8%`；⑤ 最后才动翻页停留（1.0 秒是下限，不低于 0.8 秒）。
- 加长：给每页补一句"为什么/意味着什么"的解释，或把并列项拆成独立句子——但**不能编材料里没有的事实**。
- 每次改完都要：重跑 03 → 看它打印的逐页时长与 `TOTAL` → 超上限再压缩。别靠估算拍板。
- 沿用本次所选讲解风格；课堂、科普可按 `references/narration-styles.md` 增补明确的假设例子或类比。压缩时先删重复和装饰性笑点，再缩短例子，保留必要解释；新增句子须写进 cue 的 `t`。

**D. 用户要换音色**

改 `VOICE`（见 `references/voices.md`），`TTS_RATE` 可一起改。换音色会让所有页的缓存失效（因为缓存名含音色），整片会重新配音。

**E. 用户要字幕烧进画面**

跑 `python scripts/06_burn_subtitles.py --video <成片> --srt <字幕> --out <新文件>`，默认白字 + 半透明黑底 + 底部安全边距；烧入是二次编码，画质略降，所以要**另存为副本**，不要覆盖原片。

**F. 用户要换讲解风格**

用户已明确指定新风格时直接采用，否则展示 `references/narration-styles.md` 的菜单让用户选择。更新本次 cue 文件的 `NARRATION_STYLE`，按新风格重写口播（包括例子和幽默），不能只改元信息或音色。重新执行 03 → 04 → 05；字幕由新 cue 同步生成，用户原先选择烧入时重新生成带字幕副本。所有新产物仍在 `results/`，原 PPT 与画面标记机制保持原流程。
