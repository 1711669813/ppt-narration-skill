# 提示词 03：对照稿、字幕与复核

输出位置：所有新生成的文件（含讲稿、cue、试听、报告和中间文件）保存到本包 `results/` 或其任务子目录下。

## A. 生成对照稿（`scripts/04_make_sheet.py` 已自动做，格式见下）

对照稿必须包含三块：

1. **总览表**：页码 / 页面标题 / 讲解单元数 / 字数 / 本页时长 / 起始 / 累计；
2. **逐句表**：`#` / 时间轴 / 本句时长 / 画面标记（标的是哪一块、用哪种标记）/ 讲稿；
3. **讲稿全文**：按页分段，可直接照读。

顶部信息行要写清：源文件名与页数、音色（中文名＋voice id）与语速、画面说明（标记方式、压暗、首页末页不标记）、字幕是否烧入、总时长与上限对照。

本次 cue 文件包含 `NARRATION_STYLE` 时，顶部还要写清所选讲解风格、受众、幽默程度、举例方式和补充要求；`04_make_sheet.py` 自动写入。举例与类比属于口播内容，必须同时出现在逐句表和讲稿全文，不能只放在备注里。

## B. 字幕

- 默认交付外挂 `.srt`（`03_build_video.py` 自动产出，一句一条，长句按标点折两行）；
- 需要"画面里带字幕"时跑 `scripts/06_burn_subtitles.py`，参数与注意事项见 `prompts/02` E 节。

## C. 复核（把下面这段连同成片信息一起给模型，或直接跑 `scripts/05_verify.py`）

请按顺序核对并**逐条给出实测数字**，不要只回答"看起来没问题"：

1. `ffprobe`：分辨率、帧率、编码（H.264＋AAC）、时长（是否 ≤ 上限）、是否有音轨。
2. `volumedetect`：确认不是静音（给 mean/max 音量）。
3. **逐句帧比对**：在每个 cue 时间轴中点抽帧，与"该 cue 应有的渲染帧"比像素均值差（<3 为对齐），报告最大差值出现的位置。
4. **几何检查**：对抽样的放大句，用与渲染代码**无关**的方式（纯 PIL 按 view 裁 4K 原图再缩放）与视频帧比对目标块像素；若差值 >22 或黑边比例 >1.5%，判定画面被拉伸/越界。
5. **标记与台词一致性**：抽 4–6 段 cue 的音频做 ASR，检查转写里是否出现该 cue 的关键词——确认"标的那块"＝"在讲的那句"。
6. 视觉抽查 2–3 帧：框是否正好包住目标块、压暗是否生效但不能看不清、放大后文字是否可读。
7. 人工内容复核：实际讲稿是否符合本次风格和受众；例子是否标为假设/类比并回扣知识点，是否无编造事实；新增口播是否同步进入配音、字幕与对照稿且计入总时长。此项不能仅靠 `05_verify.py` 判定。

最后给一份结论：**哪些项通过、哪些项需要修、修完要不要重渲染**。
