# cue 编写细则（逐句讲稿＋画面标记）

## 1. 数据结构

```python
CUES = {
 <页码>: [
   {
     "t":  "这一句要念出来的话（同一页所有 t 拼起来＝整页讲稿，也是 TTS 的输入）",
     "r":  [[x0, y0, x1, y1], ...],   # 要高亮的矩形，页面归一化坐标(0–1)，可多个同时亮
     "tr": ["表格 shape 名", [1, 2]],  # 可选：按表格行高亮（第 1 行是表头之后的第 1 行；0＝表头）
     "lb": "该标记的中文名（写进对照稿，用户靠它核对）",
     "z":  "auto" | "none"            # auto＝目标较小时自动放大；none＝保持整页
   },
   ...
 ],
}
```

坐标哪来：跑 `scripts/01_extract_ppt.py`，它会打印每页每个 shape 的名称为归一化包围盒，例如

```
block-121   AUTO_SHAPE  [0.044,0.376,0.264,0.469]   统计范围内用电量
表格 11      TABLE       [0.031,0.332,0.969,0.897]  表格: 业务目标 | 需要解决的问题 | 本期建设响应
```

直接抄这些数字写 `r` 即可（可略微外扩 0.003~0.01 让框好看）。

## 2. 切句规则

| 规则 | 说明 |
|---|---|
| 一页 5–10 句 | 太少＝画面长时间不动，太多＝切换碎 |
| 一句 25–60 字 | 约 5–12 秒/句；超过 60 字通常应该拆成两个画面标记 |
| 顺序＝画面阅读顺序 | 标题 → 导语 → 主体分块（左上→右上→左下→右下 / 从左到右）→ 底部口径说明 |
| 句末标点 | 真句子用"。"，同一句的列举之间用"；/，"。标点决定停顿，直接影响总时长 |
| 术语一致 | 数字、项目名、专业术语与 PPT 完全一致；写口播稿时把符号念法化（CO₂→二氧化碳、kWh→千瓦时、≤50→五十及以下），Latin 缩写保持原样（AI、H01、客户A） |
| 不编造 | 事实只用 PPT＋备注；按本次所选风格可用明确的假设情境或类比解释现有概念，边界见 `references/narration-styles.md`；页面标了"虚拟数据/占位符/待确认"就如实说一句 |
| 讲解风格 | 新任务先让用户选择，实际表达、幽默和举例按所选风格执行；例子写进 `t`，计入配音、字幕和时长 |
| 页间过渡 | 每页第一句带上过渡（"先看…""接着看…""这一页是…""最后是…"），页内不要重复"接下来" |

## 3. 画面标记规则

| 目标 | `r` 怎么给 | `z` |
|---|---|---|
| 页标题 | 标题文本框 | `none`（通栏，放大会切掉） |
| 导语/说明行 | 两行导语的联合矩形 | `none` |
| 卡片/指标块 | 单独一块卡片的矩形 | `auto`（放大后正好铺满） |
| 表格的一行 | 用 `tr`，让脚本按行高算 | `auto` |
| 整张表 | 表格整体矩形 | `auto` |
| 图表 | 图表矩形 | `auto` |
| 侧边细长条（竖栏/横条） | 该条矩形 | `none`（放大没意义） |
| 底部小字口径提示 | 该文本矩形 | `auto` |

放大判定（脚本内）：目标宽、高都 < 页面 45% 且 `z=="auto"` → 以目标为中心外扩 2.3 倍、按 16:9 取窗口，窗口宽 ≥ 页面宽 40%（保证 4K 源下清晰），并夹在页面内。

## 5. 自查清单（写完 cue 后逐条过）

- [ ] 同一页所有 `t` 拼起来读一遍，像不像人在讲（不是逐条念幻灯片）？
- [ ] 有页面目标的 `t` 是否有对应的 `r` 或 `tr`；独立举例、提问或过渡无目标时是否 `r=[]`、`m="none"`，而不是编造页面目标？
- [ ] 是否按本次所选风格写稿；假设或类比是否明确标示并回扣知识点？
- [ ] 术语/数字与 PPT 完全一致？符号都换成了口播写法？
- [ ] 页面上的"虚拟数据/占位符/待确认"都如实提到？
- [ ] 有没有横跨整页、什么都框不住的大矩形（应改成小块）？
- [ ] 按 0.194 s/字（+6%）或 0.183 s/字（+8%）估算，总时长（＋每页 1 秒）是否在上限内？
- [ ] 太长时优先删哪几句：重复的、画面已能看出的列举、可从备注省略的细节。

## 标记方式字段 `m`

每个 cue 用 `m` 指明这一句在画面上怎么标（可写在 cue 里，也可统一写在文件末尾的 `MODES` 表）：
`none` 不标记·整页原样（首页、末页、每页开头"这页讲什么"）/ `line` 下划线 / `box` 高亮框 / `zoom` 高亮框＋放大。

判定标准、压暗强度与混合原则见 `references/mark-styles.md`；
每个 cue 除了 `t`（口播）和 `r`（区域）之外还应有 `lb`（标记中文名，写进对照稿）。

一页里至少混用三种标记，连续四句不要都用同一种；首页与末页必须全部 `none`。
