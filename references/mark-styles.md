# 四种画面标记的判定规则

每个 cue 都要有一个标记，但不等于"每句都画框"。规则如下（`03_build_video.py` 里 `cue_style()` 读取每个 cue 的 `m` 字段）。

| 标记 `m` | 画面效果 | 压暗 | 放大 | 判定标准 |
|---|---|---|---|---|
| `none` | 整页原样呈现 | 0 | 无 | 首页、末页；每页开头"这页讲什么"的页标题/导语；纯过渡句、总结句 |
| `line` | 目标块下方一条圆角下划线（琥珀 + 淡光晕） | `DIM_LINE=46`（≈18% 黑） | 无 | 说明行、提示行、"待确认/口径"文字、一句话式的注释 |
| `box` | 圆角高亮框（5px 描边 + 9px 光晕） | `DIM_BOX=72`（≈28% 黑） | 无 | 较宽的元素：通栏卡片带、表格行、流程条、宽图注 |
| `zoom` | 高亮框 + 以目标为中心自动放大 | `DIM_BOX=72` | 1.1–2.5 倍 | 较小的元素：卡片、图、流程小块、表格里的一段 |

## 放大的算法（`view_rect`）

目标宽 `w`、高 `h`（均为页面比例）：

- 若 `w ≥ 0.45` 或 `h ≥ 0.45` → 不放大（返回整页）——宽元素放大没意义还会切掉上下文；
- 否则窗口边长 `need = clamp(max(w, h) * 2.3, 0.40, 1.0)`：
  - `× 2.3` 是给目标留出上下文（看到它在页面中的位置）；
  - 下限 `0.40`＝放大窗口不小于页面宽度的 40%（4K 源下仍是原生清晰度），对应最大放大 2.5 倍；
- 窗口以目标中心居中，并夹在页面内。

**归一化坐标下的关键事实**：页面本身是 16:9，所以在 0–1 坐标里"16:9 窗口"是**正方形**（`vw == vh`）。
写成 `vh = vw * 9/16` 会让窗口高度只有宽度的一半 → 裁出后 `resize(1920×1080)` 把画面**纵向拉长**，或窗口超出页面被 PIL 用**黑边**补齐。必须断言 `abs(vw - vh) < 1e-9` 且 `0 ≤ x0, x1 ≤ 1`。

## 压暗强度怎么定

- 起点：`DIM_BOX=72`、`DIM_LINE=46`（分别是 28% 与 18% 的黑）。
- 用户说"太暗" → 先降到 56 / 36；还说暗 → 40 / 28。**不要为了亮而删标记**。
- 用户说"看不住重点" → 升到 88 / 60，并考虑给该处换 `zoom`。
- 实测参考：全片压暗后，标记块内像素与原始页面一致（差 <5），标记块外亮度降到 100−dim 的灰（dim=72 → 约 72% 亮度）。

## 过渡与停留

- 句与句之间 0.4 秒（12 帧）：同时插值视图窗口（推近/拉远）与标记透明度（旧句淡出、新句淡入）；`none` 句两样都归零，因此过渡会"退回整页原亮度"。
- 标记在**声音开始前 0.14 秒**就切换，避免"字还没亮，话已经说完"。
- 每页说完留 **1.0 秒**（`PAUSE`）再翻页；翻页是硬切，不做动画（像真 PPT）。

## 混合原则（避免画面发闷）

- 一页里 `none`/`line`/`box`/`zoom` 至少出现三种；
- 连续 4 句不要都用同一种标记；
- 表格逐行讲时：行本身用 `box`（宽），表格旁的注释用 `line`，表格里的小块（如某个单元格区）才用 `zoom`；
- 讲"整页在看什么"的那一句一定 `none`。
